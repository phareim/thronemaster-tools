# Thronemaster Tools

npm package for retrieving game info from Thronemaster (Game of Thrones strategy game).

## Tech Stack

- Node.js ≥ 20.12 (ES modules)
- Cheerio for HTML parsing
- `node:util` `styleText` for CLI colors (no dependency)

## Commands

- `npm install -g` — install globally for CLI access
- `thronemaster-log` — fetch game logs
- `thronemaster-title` — fetch game titles
